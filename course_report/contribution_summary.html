Dataset + Task + Model：项目成果与评分维度

作者：Xiangwen Wang、Qichang Liu · 更新：2026-11-26

最终选择：Option 4，Dataset + Task + Model（Full Pipeline）。 LifeSnaps是PyHealth贡献的数据集，PMData用于独立研究复现。核心贡献包含数据加载、任务定义、模型、端到端训练评估、文档测试与实际消融。以下配分是rubric中的项目权重，不是已经获得的分数。

本文件按评价维度整理已完成工作及其证据；完整研究报告将同一组成果组织为连贯的研究与展示叙述。

1. Core Implementation：20分

这20分是核心实现的评分维度。Dataset、Task和Model的对应分表不简单累加成60分。

对应项目已实施工作验证结果或结论
Dataset实现LifeSnapsDataset继承BaseDataset；原始CSV准备、完整日/去重/缺失处理；YAML定义小时及每日事件实际数据得到71人、5,850完整日、228标签日；合成测试核验读取、事件和异常路径
Task实现StressDetectionLifeSnaps继承BaseTask；participant-day样本；5×24 sensor、22维context和二分类标签；无标签预训练模式监督3样本、预训练4完整日的fixture结果符合预期；STAI未进入输入
Model实现WearableStressModel继承BaseModel；双分支编码、融合、对比目标和分类；probe/fine-tune/checkpoint形状、梯度、冻结行为、目标公式和保存恢复通过测试；完整真实训练已执行
文档与类型Google-style参数/返回/异常说明、类级使用示例、方法类型标注Dataset三个方法的参数和返回标注已核对；组件API文档提供输入输出说明
代码质量模块职责分离；snake_case/PascalCase；针对性Ruff lint/format已有贡献代码检查记录；Dataset行长和命名复查通过，最长87字符

错误处理覆盖未知非空STAI类别和无完整日等情况。缺文件、坏列仍主要使用pandas底层异常；全量静态类型检查、所有输入边界与所有运行环境不在已有验收结论之内。

4. Ablation Study / Example Usage：5分

Dataset/Task路线的要求是特征或任务配置变化、用现有PyHealth模型展示性能比较，并记录设置与findings；我们使用PyHealth MLP直接落实这组实验。完整CLSP路线进一步加入目标和文字机制控制及日历干预。CLI有合成短流程，真实结果由真实数据运行产生。

实验已完成的受控比较实测结果与结论
MLP输入模态both/sensors/context，三seed；固定同seed划分，各配置重训AUC69.50±3.57 / 68.19±1.70 / 55.51±18.08%；sensor-only与双模态均值接近，context-only波动大
MLP观测偏移offset1/7，按历史观测数量移动context并重训69.33±0.89 / 70.79±2.29%；未呈单调下降，属于训练任务变化
日历context干预k0/1/3/7；仅改变动态context，固定模型和测试行supervised同日52.83±3.51%、7日50.00±6.04%；reference同日50.03±7.65%、7日51.44±10.18%；全部下降差配对CI包含0，未建立CLSP更抗过期的证据
文本机制pretrained frozen BERT / random frozen BERT / statistics；同seed、数据和预算，分别重训50.03±7.65 / 52.50±19.80 / 45.13±8.82%；未建立稳定预训练语言收益，统计控制还改变了表示和缩放
对比目标reference / stop_gradient / one_hot；同seed保持其他条件50.03±7.65 / 50.08±12.98 / 47.55±9.17%；未发现稳定优胜者，reference用于对齐目标梯度行为
AUC诊断固定预测，按同人/跨人正负配对分解93–94%的配对来自不同人；总体AUC不足以证明个体每日跟踪能力

±均为三seed总体SD，不是CI。MLP和CLSP协议不同，其绝对分数不是直接模型排名。AUC分解是诊断、bootstrap是统计方法，不单独算作新的训练消融。CLSP有9次目标训练和6次新增文字训练，共15次；MLP另有15次。真实日历实验没有触发fallback，合成测试覆盖该边界。

模型细项列举了超参数变化和现有数据集实验；我们实际报告的是目标/文字机制控制以及新接入LifeSnaps上的完整流程，没有将其冒充lr/hidden-dimension网格搜索。Full Pipeline的具体评分归属和消融novelty由教师判定。普通模态变化本身不作为新增研究创新的唯一依据。

9. 统一结论

工程结果是一个实际运行、可测试、带文档与实验记录的Dataset + Task + Model全流程。科学结果是在当前固定协议与有限预算下，CLSP未显示稳定预训练优势，文字机制与旧context鲁棒性也未得到稳定支持；同人/跨人分析进一步限定了总体AUC的解释范围。两类结果共同构成项目成果。
